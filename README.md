## 项目定位

这不是一个传统的商户管理后台，而是一个**经营议题操作系统**的产品样板。

核心命题：当商业地产的总经理面对一个高风险商户续约问题时，他需要的不是一张报表，而是一个能帮他**发现问题 → 联合研判 → 做出决策 → 追踪执行 → 沉淀经验**的完整工作流。

`/workspace` 页面是这个命题的完整演示。

---

## 核心架构：4 个业务对象

### 1. 议题生命周期状态机
每个经营议题都有完整的生命周期：

```
自动识别 → 建议升级 → 联合研判中 → 等待请示 → 等待拍板
                                                    ↓
已沉淀 ← 待复盘 ← 执行中 ← 已拍板 ←────────────────┘
```

每个状态明确：状态含义 / 进入条件 / 下一步动作 / 当前责任方 / 是否需要总经理介入。

### 2. 决策对象
"拍板"不是一个按钮，而是一个业务对象，包含：
- 决策问题 / 可选方案 / 推荐方案 / 推荐理由
- 关键依据（来自证据账本）/ 风险与代价
- 决策人 / 截止时间 / 验证指标

### 3. 证据账本
Agent 发言背后的依据结构化存储，支持 6 种证据类型：
经营数据 / 现场证据 / 历史案例 / 招商判断 / 活动数据 / 客诉反馈

每条证据包含：摘要 / 提供者 / 更新时间 / 支撑的判断 / 可信度。

### 4. 执行验证闭环
拍板后不只生成任务，还追踪结果：
- 执行任务 / 责任人 / 截止时间
- 预期领先指标 / 实际结果 / 是否达标
- 复盘结论 / 是否沉淀为组织记忆

## /workspace 页面结构

四区布局，每区有明确的视觉语义：

```
┌─────────────────────────────────────────────────────────┐
│  Tab Bar：今日经营 / 风险研判 / 招商协同 / 活动复盘 / 组织经验  │
├──────────────┬──────────────────────────┬───────────────┤
│  左栏（冷灰）  │      中栏（白色）           │  右栏（暖黄）  │
│              │                          │               │
│  经营事项盘   │   联合研判主线程            │  当前决策对象  │
│              │                          │               │
│  · 生命周期   │   · 8阶段状态流转          │  证据账本摘要  │
│    状态标签   │   · 状态流转卡             │               │
│  · 当前责任方 │   · Agent 发言            │  执行验证闭环  │
│  · 下一步动作 │   · 总经理决策             │               │
│              │   · 方案拍板工具           │               │
│              │   · 任务生成              │               │
│              │   · 记忆沉淀              │               │
├──────────────┴──────────────────────────┴───────────────┤
│                    总经理主持控制台                        │
└─────────────────────────────────────────────────────────┘
```

**左栏**（`#f1f5f9` 冷灰）：导航/索引属性，退到背景
**中栏**（纯白）：主内容区，最亮最干净
**右栏**（`#fffbeb` 暖黄）：需要你关注/决策的区域，天然成为视觉焦点

## 演示流程（望潮港火锅续约风险）

打开 `/workspace` 后，AutoPlay 引擎自动演示完整的 8 阶段研判流程：

| 阶段 | 内容 | 状态流转 |
|------|------|---------|
| 发现 | 风险诊断师检测到 P0 级续约风险 | 自动识别 → 建议升级 |
| 证据 | 4 位 Agent 补充经营/活动/现场/案例证据 | → 联合研判中 |
| 请示 | 超出 Agent 权限，请示总经理邀请招商经理 | → 等待请示 |
| 判断 | 招商经理补充续约侧信息，修正初始判断 | → 联合研判中 |
| 方案 | 任务调度官收敛 3 个方案，8 维度对比 | → 等待拍板 |
| 决策 | 总经理拍板方案 B，批第一阶段预算 | → 已拍板 |
| 执行 | 生成 4 项执行任务，同步各责任人 | → 执行中 |
| 沉淀 | 案例记忆官归档，反哺下次同类判断 | → 已沉淀 |
