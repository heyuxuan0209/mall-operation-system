# 演示模式使用说明

## 功能说明

演示模式确保AI助手对特定问题返回固定的响应内容，使演示视频中的AI响应与旁白音频完全一致。

## 启用方法

### 方法1：环境变量（推荐）

在项目根目录创建 `.env.local` 文件（如果已存在则编辑）：

```bash
# 启用演示模式
NEXT_PUBLIC_DEMO_MODE=true
```

然后启动开发服务器：

```bash
npm run dev
```

### 方法2：临时启用

```bash
NEXT_PUBLIC_DEMO_MODE=true npm run dev
```

### 方法3：生产构建

```bash
# 构建时启用
NEXT_PUBLIC_DEMO_MODE=true npm run build

# 启动
npm start
```

## 关闭演示模式

删除或注释掉 `.env.local` 中的配置：

```bash
# NEXT_PUBLIC_DEMO_MODE=true
```

或者直接运行：

```bash
npm run dev
```

## 演示问题列表

演示模式支持以下固定问题（精确匹配或模糊匹配）：

### 第二幕：智能诊断
1. **"海底捞健康度如何"**
   - 返回：健康度45分、高风险状态、关键指标
   - 建议操作：查看健康度详情

2. **"对海底捞问题诊断分析"**
   - 返回：根因分析、恶性循环、推荐案例
   - 建议操作：查看知识库

### 第三幕：档案查询与方案推荐
3. **"海底捞历史上有过帮扶记录吗"**
   - 返回：2次历史帮扶记录
   - 建议操作：查看历史档案

4. **"有什么好的帮扶方案吗"**
   - 返回：3个成功案例 + 定制化方案
   - 建议操作：创建帮扶任务

### 第四幕：效果评估
5. **"海底捞和上月对比怎么样"**
   - 返回：对比数据表格、改善点、趋势预测
   - 建议操作：查看健康度详情

6. **"把这次海底捞帮扶经验沉淀到知识库"**
   - 返回：案例草稿信息
   - 建议操作：保存到知识库

## 验证演示模式

启动服务后，在浏览器控制台查看日志：

```
[AgentRouter] 🎬 演示模式激活，返回固定响应
[DemoMode] 精确匹配: 海底捞健康度如何
```

## 注意事项

1. **精确匹配优先**：系统会先尝试精确匹配问题
2. **模糊匹配兜底**：如果精确匹配失败，会去除标点和空格后再匹配
3. **非演示问题**：如果问题不在演示库中，系统会正常调用LLM API
4. **不消耗API**：演示模式下不会调用真实的LLM API，节省成本

## 录制演示视频流程

1. **启用演示模式**
   ```bash
   NEXT_PUBLIC_DEMO_MODE=true npm run dev
   ```

2. **打开浏览器**
   访问 http://localhost:3000

3. **开始录制**
   使用 Screen Studio 或其他录屏软件

4. **按脚本提问**
   严格按照演示脚本中的问题输入（支持复制粘贴）

5. **验证响应**
   确认AI返回的内容与旁白音频一致

6. **完成录制**
   保存视频文件

## 添加新的演示问题

编辑 `skills/ai-assistant/demo-mode.ts`：

```typescript
export const DEMO_RESPONSES: Record<string, DemoResponse> = {
  // 添加新问题

    content: `你的固定响应内容`,

    suggestedAction: {
      type: 'navigate_health',

      merchantName: '海底捞火锅'
    }
  },

  // ... 其他问题

```

## 故障排查

### 问题1：演示模式未生效
- 检查环境变量是否正确设置
- 重启开发服务器
- 检查浏览器控制台是否有 `[DemoMode]` 日志

### 问题2：问题匹配失败
- 检查输入的问题是否与演示库中的完全一致
- 查看控制台日志：`[DemoMode] 未找到匹配的演示响应`
- 尝试复制粘贴演示库中的问题

### 问题3：响应内容不对
- 检查 `demo-mode.ts` 中的响应内容是否正确
- 确认没有修改过演示库中的内容

## 生产环境注意

⚠️ **重要**：生产环境部署时，请确保 `NEXT_PUBLIC_DEMO_MODE` 未设置或设置为 `false`，否则所有用户都会看到固定的演示响应！

```bash
# 生产环境构建（不启用演示模式）
npm run build
npm start
```
