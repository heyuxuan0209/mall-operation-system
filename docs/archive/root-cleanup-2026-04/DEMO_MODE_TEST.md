## 测试步骤

### 1. 重启开发服务器

```bash
# 停止当前服务器（Ctrl+C）
# 重新启动
npm run dev
```

### 2. 打开浏览器

访问：http://localhost:3000

### 3. 测试演示问题

在AI助手中依次输入以下问题，验证返回的是固定响应：

#### 第二幕测试
- [ ] **"海底捞健康度如何"**
  - 预期：返回健康度45分、翻台率1.2次/天等固定内容
  - 检查：控制台显示 `[DemoMode] 精确匹配`

- [ ] **"对海底捞问题诊断分析"**
  - 预期：返回根因分析、恶性循环、推荐案例
  - 检查：控制台显示 `[AgentRouter] 🎬 演示模式激活`

#### 第三幕测试
- [ ] **"海底捞历史上有过帮扶记录吗"**
  - 预期：返回2次历史帮扶记录
  - 检查：显示"查看历史档案"按钮

- [ ] **"有什么好的帮扶方案吗"**
  - 预期：返回3个成功案例 + 定制化方案
  - 检查：显示"创建帮扶任务"按钮

#### 第四幕测试
- [ ] **"海底捞和上月对比怎么样"**
  - 预期：返回对比数据表格
  - 检查：显示健康度从45分提升到68分

- [ ] **"把这次海底捞帮扶经验沉淀到知识库"**
  - 预期：返回案例草稿信息
  - 检查：显示CASE_032案例信息

### 4. 验证控制台日志

打开浏览器开发者工具（F12），查看Console：

```
✅ 应该看到：
[AgentRouter] 🎬 演示模式激活，返回固定响应
[DemoMode] 精确匹配: 海底捞健康度如何

❌ 不应该看到：
[LLM] Calling API...
[QueryAnalyzer] Analyzing query...
```

### 5. 测试非演示问题

输入一个不在演示库中的问题，例如：
- **"今天天气怎么样"**
  - 预期：正常调用LLM API，返回动态响应
  - 检查：控制台显示 `[DemoMode] 未找到匹配的演示响应`

## 故障排查

### 问题：演示模式未生效
```bash
# 1. 检查环境变量
cat .env.local | grep DEMO_MODE

# 2. 重启服务器
# Ctrl+C 停止
npm run dev

# 3. 清除浏览器缓存
# 硬刷新：Cmd+Shift+R (Mac) 或 Ctrl+Shift+R (Windows)
```

### 问题：响应内容不匹配
- 检查输入的问题是否与演示库完全一致
- 尝试复制粘贴演示库中的问题
- 查看 `demo-mode.ts` 中的 `DEMO_RESPONSES` 内容

### 问题：按钮不显示
- 检查 `suggestedAction` 配置是否正确
- 查看浏览器控制台是否有错误信息
